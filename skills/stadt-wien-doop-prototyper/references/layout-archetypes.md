# Layout archetypes

Starting sequences for a brief that does not already name its sections. They are editorial notes from live pages on 2026-10-16, not handbook templates. Open the live URL before trusting a sequence. If it redirects or is gone, record the page you used instead.

Build each line by fetching the pattern named in [pattern-index.md](pattern-index.md). Skip a section that does not help the citizen task.

## When the brief is a type rather than a URL

- **Article or report.** Header, title and introduction, article sections at a readable width, a link list, contact, footer. Do not invent statistics to fill a fact box.
- **Service hub.** Header, icon tags, stage with a CTA, the task cards, quicklinks to the frequent tasks, contact, footer. News must not push the task off the page.
- **Project or construction page.** Header, title, stage image, verified status and dates, detail cards, a map placeholder, contact, footer. Mark anything that would be live data as simulated.

Breadcrumbs are not on current wien.gv.at pages. The parent channel is a tag with a left chevron. Add a breadcrumb only when the live page has one.
